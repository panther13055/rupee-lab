# RUPEE LAB

An interactive economy experience built as a companion to a magazine article about the Indian rupee.

## Features
- USD/INR exchange-rate simulator
- Five-question currency prediction game
- Selected historical USD/INR annual-average timeline (rounded and illustrative)
- Economic impact explorer for energy, travel, education and exports
- Responsive dark fintech-inspired interface

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Deploy on Vercel
Import this GitHub repository into Vercel. Select **Other** as the framework preset if prompted, leave the build command empty, and set the output directory to `.`.

## Data and limitations
- The reference-rate panel requests the latest available USD/INR reference rate from the public Frankfurter API. It is not a live trading quote and may be unavailable temporarily.
- Simulator values are hypothetical and educational.
- Historical chart values are rounded illustrative annual-average levels. Verify exact values from official RBI or other authoritative datasets before using them in formal publication.
- This project is educational and does not provide investment advice.
